# Perfils anonimitzats dels participants

## Criteris aplicats

Tots els perfils del test compleixen els criteris d'inclusio:

- Edat entre 18 i 30 anys.
- Estudiant universitari/aria o recent graduat/ada.
- Us habitual de smartphone.
- Comprensio suficient del catala per seguir la UI.
- Cap contacte previ amb el prototip Pila-Plats.

S'han exclòs perfils professionals de UX o desenvolupament web per evitar biaix
de coneixement. No es recull cap nom real, email, compte de Google ni
informacio identificable.

## Notes de reclutament anonimitzades

| Codi | Raó de pertinenca al test | Risc de biaix detectat |
|------|---------------------------|------------------------|
| P1 | Gestiona pressupost alimentari de pis compartit i cuina sovint. | Cap declarat. |
| P2 | Perfil novell en planificacio d'apats, adequat per provar descobribilitat. | Menys experiencia cuinant. |
| P3 | Planifica compra i carmanyoles amb eines generiques. | Pot comparar amb llistes externes. |
| P4 | Necessita opcions rapides i no usa apps similars. | Sessions mes exploratories quan hi ha molts passos. |
| P5 | Usa receptes digitals i reconeix patrons de navegacio d'escriptori. | Cap perfil tecnic declarat. |
