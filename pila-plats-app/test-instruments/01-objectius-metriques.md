# Objectius i mètriques del test d'usabilitat — Pila-Plats

## Objectius generals del test
1. Validar que els usuaris poden completar les 3 tasques principals sense ajuda
2. Identificar problemes d'usabilitat que impedeixen o dificulten la navegació
3. Mesurar el grau de satisfacció percebuda amb la interfície
4. Detectar elements confusos o que generen dubtes
5. Comprovar si els canvis de preferències, regeneració de menú i saltar plats s'entenen com un flux coherent

## Criteris d'inclusió dels participants
- Edat: 18-30 anys
- Situació: estudiant universitari/ària o recent graduat/ada
- Experiència tecnològica: usuari/ària habitual de smartphone (mínim 2h/dia)
- No és necessari que hagin usat apps de planificació de menús prèviament
- Preferiblement que cuinin o gestionin la seva pròpia alimentació

## Criteris d'exclusió
- Professionals del disseny UX o desenvolupament web (biaix de coneixement)
- Persones que hagin vist o provat el prototip prèviament
- Persones que no entenguin el català (la UI és en català)

## Mètriques quantitatives

| Mètrica | Com es mesura | Valor objectiu |
|---------|---------------|----------------|
| Taxa d'èxit Tasca 1 | % participants que completen la tasca sense ajuda | ≥ 80% |
| Taxa d'èxit Tasca 2 | % participants que completen la tasca sense ajuda | ≥ 70% |
| Taxa d'èxit Tasca 3 | % participants que completen la tasca sense ajuda | ≥ 60% |
| Temps Tasca 1 | Temps des que s'obre l'app fins a marcar 3 elements de compra (en seg) | ≤ 300s |
| Temps Tasca 2 | Temps des de la detecció de l'ingredient fins a "He acabat!" (en seg) | ≤ 300s |
| Temps Tasca 3 | Temps des de l'inici de preferències fins a comprovar menú, pressupost i llista (en seg) | ≤ 300s |
| Nombre d'errors Tasca 1 | Clics incorrectes o navegació equivocada | ≤ 2 per participant |
| Nombre d'errors Tasca 2 | Clics incorrectes o navegació equivocada | ≤ 2 per participant |
| Nombre d'errors Tasca 3 | Clics incorrectes, canvis no desats o comprovacions incompletes | ≤ 3 per participant |
| Puntuació SUS | Qüestionari System Usability Scale (10 ítems) | ≥ 70 (acceptable) |

## Mètriques qualitatives

- Punts de confusió: moments on el participant s'atura, verbalitza dubte o mira sense actuar
- Terminologia: paraules o etiquetes que no s'entenen o es malinterpreten
- Satisfacció emocional: expressions de frustració, alleujament, sorpresa positiva/negativa
- Suggeriments espontanis: millores proposades pels participants de manera natural
- Think-aloud: transcripció de raonaments verbalitzats durant les tasques
